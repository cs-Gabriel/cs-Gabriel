**Competências:** Power BI, modelagem de dados, ETL, indicadores de desempenho e visualização de dados.

Desenvolvimento de pipelines e rotinas de integração para extração, transformação, validação e atualização de bases de dados a partir de APIs e sistemas institucionais.

**Competências:** Python, SQL, APIs REST, Google Apps Script e qualidade de dados.

### 🤖 Inteligência Artificial e automação

**Tecnologias:** Ollama, n8n, Python e LLMs locais.
